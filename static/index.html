🗺 Estimasi rute antar lokasi

Memeriksa layanan estimasi perjalanan…

Tanpa Google Routes API atau API key Google. Estimasi dihitung dari OSRM, opsional OpenRouteService, serta waktu cadangan. Tidak mencakup kemacetan aktual; rute yang sama bisa memiliki waktu perkiraan sama.

Transfer kepulangan

Lokasi yang belum punya koordinat dapat dicari satu per satu melalui tombol Cari koordinat pada destinasi. Rute demo hanya dipakai saat pengecekan dan tidak menjamin ETA lalu lintas. Sebelum itu aplikasi memakai pendekatan jarak, bukan ETA kemacetan live.

Hotel, transport lokal dan lainnya

Biaya dibuat transparan dan bisa diubah. Ketentuan usia berbeda antar penyedia wisata, transportasi, penginapan dan operator.
